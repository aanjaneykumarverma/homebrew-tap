# homebrew-tap

Homebrew formula and release binaries for [lidhold](https://github.com/aanjaneykumarverma/homebrew-tap), which keeps your Mac
awake with the lid closed while coding agents work.

```sh
brew install aanjaneykumarverma/tap/lidhold
lidhold setup
```

macOS 14 or newer. Current builds are Apple Silicon; Intel builds follow when the release machine gains an x86_64 target.
